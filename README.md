# Your Backend is Showing: An Introduction

Stop writing the same API calls twice! This presentation, "Your Backend is Showing", demonstrates how to auto-generate frontend SDKs so you don't have to. We'll explore the pain of manual API client maintenance and present a robust solution using OpenAPI as a single source of truth.

We will cover:
*   **The Problem**: The challenges and pitfalls of manually keeping frontend clients in sync with backend APIs.
*   **The Solution**: Leveraging the OpenAPI specification and code generation to automate the creation of client SDKs.
*   **Backend**: How to use FastAPI to automatically generate an OpenAPI specification from your Python code.
*   **Frontend**: Generating a type-safe TypeScript SDK for your web application using HeyAPI.
*   **Mobile**: Creating a Dart SDK for your Flutter application with `openapi_generator`.

By the end of this presentation, you'll understand how to build a development workflow that eliminates redundant work, reduces bugs, and allows your team to focus on building features instead of writing boilerplate API code.
